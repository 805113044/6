# 上线验收清单

在真实子域名完成以下操作，并同时检查已有主站仍正常。请使用测试用学生信息，上线前清理测试记录或等待正常保留期清理。

## 功能

- [ ] 管理员成功登录、添加真实教室和教师账号，教师可修改密码。
- [ ] 学生不登录可筛选教室、查看占用、填写学生信息提交申请，结果为“待审批”。
- [ ] 提交成功保存随机凭证；另一浏览器凭证查询成功，错误凭证不能查询，凭证不出现在 URL。
- [ ] 管理员批准/驳回申请，驳回必须填写理由；学生查询可见结果。
- [ ] 教师登录后提交，立即为“已批准”。
- [ ] 两个浏览器同时抢同教室重叠时段，只允许一个成功；相邻时段可用。
- [ ] 待审申请占用时段；驳回/取消释放时段。距开始不足 30 分钟普通用户不能自行取消，管理员可带原因撤销。
- [ ] CSV 预览不写数据，确认导入写入；重复文件跳过；冲突时整批不写入。
- [ ] 统计/CSV 导出正确，不含学生个人信息；公开课表也不显示用途或申请人。
- [ ] 学院管理员无法审批其他学院或全校共享教室，系统管理员可处理全部。

## 部署和隔离

- [ ] 新子域名 HTTPS 证书正确，HTTP 跳转到该子域名 HTTPS。
- [ ] 主域名 DNS、站点配置、证书、目录和数据库未被替换，主站功能复查通过。
- [ ] `web` 与 `retention` 均 healthy，`/healthz/` 正常且实际连接数据库。
- [ ] `docker compose restart web retention` 后功能仍可用，数据仍在。
- [ ] `18080` 仅绑定本机；数据库未新增公网端口，专用账号无主站库权限。
- [ ] 生产 `DEBUG=false`，强随机 SECRET_KEY，`.env` 权限 600，不在 Git 或公共目录。
- [ ] 仅对子域名下发 `__Host-classroom_session`、`__Host-classroom_csrf`，没有 `Domain=.主域名`。
- [ ] 服务器资源余量充足，应用未使用主站网络、目录、卷或账号。

## 数据保留与运维

- [ ] 确认在线保留 45 天，所有相关备份/日志/快照最多 14 天，或按数据保留文档配置替代策略。
- [ ] 清理容器监控和故障通知可用，不能忽略 unhealthy。
- [ ] 新系统数据库备份已加密、自动过期，并实际演练恢复后先清理过期数据再开放服务。
- [ ] 学生知晓查询凭证需要保管、身份由管理员核验、无短信/邮件通知。

本仓库自动测试验证的是测试环境，不替代上述腾讯云真实环境验收。
