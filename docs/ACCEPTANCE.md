# 新版上线验收

在真实子域名使用示例数据验证以下流程，并复查已有主站仍正常；云开发环境测试不替代腾讯云验收。

- [ ] 只有管理员账号能登录。普通学生/教师免账号，完整填写姓名、学号/工号、班级、联系方式、本次密码后直接占用。
- [ ] 所有人在卡片、日表、周表中可见借用人姓名；匿名 HTML 中没有学号、学院、联系方式、用途或密码。
- [ ] 查询页使用学号/工号 + 密码列出所有匹配记录，不需要预约编号；单笔链接验证仅授权对应记录，错误密码不授权。
- [ ] 不同预约可使用不同密码，不能验证一次就编辑同学的预约。
- [ ] 本人可改姓名、身份资料、用途、人数、教室、时间；冲突会失败并保留原预约。
- [ ] 改密码/身份后旧授权立即失效；验证 15 分钟后失效，结束验证按钮立即失效。
- [ ] 管理员能看全部详细信息、编辑预约、带原因退回/撤销；普通用户无此权限。
- [ ] 退回立即释放时段，重新提交再次检查冲突；管理员编辑和退回有操作记录。
- [ ] 同教室并发预约仅一个成功；换教室编辑与新申请同时抢时段也仅一个成功。
- [ ] 楼层、人数、教室/实验室类型、日期和固定空闲节次筛选正确。
- [ ] 日表、周表切换和前后翻页正常；手机与电脑是相同表格，显示五节实际时间，上下左右滑动、固定表头和教室列正常。
- [ ] CSV/XLSX 日期与学期模板可下载；单双周按学期周数计算，星期和排除日期正确。
- [ ] 课表预览不保存，确认导入保存，重复文件跳过，任一冲突整批回滚。
- [ ] 调整单次课程后不被同步重新生成；停止规则取消其未来占用。
- [ ] 超过预约窗口的学期课程仍显示计划信息；后台运行可滚动展开占用。
- [ ] 统计导出不含个人信息，导出公式前缀转义。
- [ ] 新子域名 HTTPS 正确，HTTP 跳转，仅本机暴露 18080，数据库不新增公网端口。
- [ ] 主站 DNS、配置、证书、目录、数据库、容器及访问功能均正常。
- [ ] web 与 retention 均 healthy；重启后数据库、清理和课表同步正常。
- [ ] DEBUG=false、独立强密钥、.env 权限 600，无凭据入库入包，安全 Cookie 不共享主域名。
- [ ] 在线记录 21 天 + 全部相关备份/日志/快照最长 7 天，或符合 DATA_RETENTION.md 的替代策略。
- [ ] 清理/同步进程监控告警正常；恢复备份后先清理、同步再开放服务。
- [ ] 从旧版升级前有可恢复备份；知道旧普通账号会停用，旧无密码预约由管理员核实处理。

身份资料为自填，预约密码验证记录控制权，不自动证明学籍/工号真实性。

- [ ] 无预建教室时，直接上传模板 Excel 可自动创建教室和实验室；未知容量/楼层显示待补充。
- [ ] 管理员手动创建/编辑教室正常，普通用户不能访问这些管理页面。
- [ ] 学期起止、起始周数、开关生效；学期外/暂停后不能提交新借用。
- [ ] 上午两节、下午两节、晚上第五节；普通界面没有自定义钟点输入，篡改 POST 也不能借用任意时段。
- [ ] 正式课程部分覆盖某节时，该整节不可借；远期及正在进行的课程也不会漏挡。
- [ ] 电脑和手机的同一张表均可直接点击某个固定节次进入借用，页面不被宽表格撑出横向溢出。
- [ ] GitHub 可见性需由所有者按 GITHUB_PRIVATE.md 操作，确认 Private 标记；本次 API 受限没有代改成功。

- [ ] 当日临时借用：开始前不必提前申请；本节已开始但未结束也能借用空闲教室，课程/其他预约仍阻止冲突。
- [ ] 本节结束前本人可修改或取消；已结束的新借用失败。管理员可退回进行中的借用。
- [ ] 管理员登录统一进入管理中心；负责人可创建多个独立管理员，停用/重设密码有效，其他管理员无账号管理权。
- [ ] 平台名称为“教室借用平台”；手机和电脑打开各页面均无旧名称。
- [ ] 浏览器请求仅指向自己的子域名；服务器不依赖第三方 API、短信、CDN、字体或在线验证码。预装软件/镜像后断开公网仍能完成核心业务（客户端至服务器及自己的数据库网络需可达）。
