# 新版交付验证

当前验证发生在开发云环境，不表示已部署腾讯云或完成真实学校上线验收。

| 检查 | 结果 |
| --- | --- |
| 业务测试 | SQLite 36 项通过，2 项行锁并发测试明确跳过；MySQL 8.4 的 38 项全部通过 |
| 身份与隐私 | 普通账号不能登录；公开姓名，其他资料鉴权；按笔验证、密码哈希、授权过期/版本撤销、禁止越权修改 |
| 编辑与管理 | 改时段冲突回滚、管理员编辑/退回、退回释放与重提抢占、取消截止、审计 |
| 课表 | 单双周/星期/排除日期、CSV/XLSX、预览回滚、重复导入、规则冲突、调课例外、停止规则、长期规则与短期记录清理 |
| 浏览器 | Chromium 跨浏览器直接预约 → 姓名公开/隐私检查 → 验证 → 修改时间/密码 → 旧浏览器与旧密码失效 → 新密码取消，成功 |
| 界面 | 周表、日表和卡片；390 px 手机页面无横向溢出（课表区域可横向滚动），无脚本错误 |
| 依赖 | Python 锁定 MySQL 运行依赖经 pip-audit，未发现已知漏洞；不包括 OS/云平台审计 |

MySQL 并发测试检查两个普通用户同时预约仅一个成功，以及“编辑换教室”与“新预约”同时抢目标时段仅一个成功。本次 Docker 镜像构建成功，旧库升级迁移及课表同步命令在生产配置下验证；Web 与清理/同步容器的健康检查包含实际数据库访问与心跳。

生产安全检查保留已说明的 HSTS 建议 W005/W021（不设置 includeSubDomains 或预加载），不隐藏这些警告。部署人员仍需验收真实域名证书、云数据库网络与专用账号、主站隔离、备份期限、监控告警及负载容量，参见 ACCEPTANCE.md。
