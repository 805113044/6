# 开发约定

仅两种使用方式：管理员账号（is_staff）和免账号普通用户。保留旧 User.role 字段仅作兼容，不再用于业务授权。旧非管理员账号在迁移 0003 中停用。开放教室全部可预约，部门仅为资料，不决定权限。

公开内容为借用人姓名及占用时间；具体用途、学号/工号、班级和联系方式只能由管理员或该笔验证通过的本人查看。所有详情/编辑/取消请求必须后端鉴权，不能只隐藏按钮。

普通预约立即批准。单笔验证使用“学号/工号 + 本次密码”；查询页不要求预约编号，可列出同一凭据匹配的多笔记录。密码采用 Django 默认 PBKDF2；15 分钟会话授权按记录分别绑定 pk 和 credential_version，批量验证不会越权到其他学号或其他密码的记录。编辑身份资料/密码使版本递增，立即撤销旧授权；事务锁内再次校验版本，防止并发密码变更后旧请求仍成功。密码不是学校密码，不验证学籍，遗失由管理员核实处理。

全部占用写入走 booking/services.py 或 timetable.py。MySQL InnoDB READ COMMITTED 下先锁教室，多个教室按主键顺序锁，再检查/修改预约。编辑冲突必须回滚，禁止偷偷覆盖其他记录。管理员退回释放占用，本人修改重提恢复 approved 并重新检查。Django admin 的预约模型保留只读，界面“预约管理”提供安全编辑入口，避免绕过锁协议。

学期规则通过 occurs_on 根据第一周周一、周次、单双周、星期和排除日期计算。导入先验证所有规则的未来冲突，再物化可预约窗口。后台每小时同步；预约即时检查规则以防同步延迟。course_key 是规则与原日期的稳定标识，单次调课/取消后保留该 key，防止被重新生成。停止规则会取消未来物化记录。计划课程可计算展示远期周，不延长具体预约行的保留期。

教室预约从使用结束或提前处理时间起保留 90 天；桌椅登记从实际归还时间起保留 90 天，未归还记录不自动删除。北京时间 Asia/Shanghai。SQLite 仅用于单人开发，不保证并发预约。

当前云任务已有隔离环境，使用现有 checkout，不创建额外 Git worktree。验证先 collectstatic，再执行 makemigrations --check --dry-run、test；涉及 SQL 和锁的变化必须在 MySQL 跑并发测试。生产仍用独立容器网络、目录、专用数据库账号及子域名；不能影响主站。构建所需代理通过标准 build args 配置，受信 CA 通过可选 BuildKit secret build_ca 提供，保持 TLS 和 APT 签名验证。

## 学期、固定节次与 Excel

AcademicTerm 为当前学期单例；未配置或关闭开关不允许新借用，学期外也不允许。first_week 是 starts_on 所在教学周编号；week_one_monday 是与课程周次一致的第一周锚点。BorrowPeriod 恰好五行，上午两节、下午两节、晚上一节，普通表单不包含 start/end，服务层再次检查起止必须完全匹配某个固定节次。每笔普通借用只占一节；课程可用任意真实起止时间并阻止所有重叠节次。

编辑/新建/课表导入先锁学期，再按主键顺序锁教室；学期与钟点设置也锁同一学期行，以防配置更新与预约并发不一致。取消/停止规则只释放资源，不延长记录。

中文 Excel 表头在 forms.py 归一化，支持第一张工作表、周次范围/单双周、连续课程节次及可选教室资料。ensure_import_rooms 在同一事务内 get_or_create；预览及冲突回滚都包含新房间。未知容量/楼层保留 NULL，不猜测真实值。

所有正式课程，包括单一日期的课程，都保存为 TeachingRule 配置，再滚动展开占用。需要包含正在进行但尚未结束的课程，防止导入时漏挡下一节。0007 将旧版未来日期课程转为教学配置。旧式任意钟点借用继续按实际时间阻挡新固定节次，不强行改动已有预约。

新借用窗口最多 14 天。B22 R3 本地数据库备份保留 30 天；业务数据的在线保留逻辑见 [DATA_RETENTION.md](DATA_RETENTION.md)。


## 临时借用、凭据查询与管理员

五个固定时段只要 end_at > now 即可借用，不要求提前，正在进行的空闲节次可借其剩余时间。预约行仍保存完整节次的起止，created_at 为实际提交时间；这让整节课程/其他预约冲突、列表显示与事务检查保持一致。本人可在结束前编辑或取消；结束后由管理员核实处理。管理员可退回进行中的借用。界面空闲条件与服务端相同，不能因为取消提前量阻断临时借用。

credential_tag 是基于服务器 SECRET_KEY 的 HMAC-SHA256（学号/工号、原密码的无歧义 JSON），仅作内部精确查询索引；PBKDF2 仍是密码验证。查询先验证匹配组中的一笔 PBKDF2，再给相同服务器密钥标签的记录逐笔授权，其他标签不授权。数据库泄露者没有服务器密钥，不能直接离线枚举此索引。旧记录/管理员无密码修改学号后的空标签记录仍走 PBKDF2 并回填索引。不能把原密码、索引标签写入会话、日志或客户端。密钥轮换请按 LOCAL_ONLY.md 清空索引重新回填。

管理中心对所有启用的 is_staff 账号开放。只有 is_superuser 系统负责人可创建/停用普通管理员及重设密码；表单强制 is_staff=True、is_superuser=False，不能通过 POST 自提权。负责人账号受保护；账号管理写 Django 管理日志。停用账号或改密后旧会话不再能访问后台。

手机和电脑使用同一个表格模板，表格自身 overflow:auto、限定高度、固定顶栏/教室列，移动端不切换成折叠日期卡片。所有字体、样式、脚本在本机，线上不访问第三方业务服务。
